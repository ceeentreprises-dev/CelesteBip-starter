# Feuille de route

Les éléments ci-dessous sont des intentions, pas des promesses de date. Chaque étape est mesurable et réversible.

## Étape 1 : fondations (fait)
- [x] Générateur d'une page + un PDF, sans dépendance obligatoire
- [x] Contrôles automatiques (17) et tests unitaires
- [x] Soutien désactivé par défaut, protégé par trois validations locales

## Étape 2 : qualité
- [ ] Version anglaise du texte de la page et du guide
- [ ] Vérification d'accessibilité (contrastes, lecteurs d'écran)
- [ ] Exemples de personnalisation (nom, couleurs, textes) via un fichier de configuration

## Étape 3 : pédagogie
- [ ] Deuxième guide gratuit : vérifier les réponses d'une IA
- [ ] Exemples d'exercices pour enseignants et formateurs

## Étape 4 : communauté
- [ ] Modèles d'issues et de pull requests
- [ ] Liste publique des contributeurs

## Principes
Simplicité d'abord. Confidentialité d'abord. Rien n'est ajouté s'il ne sert pas un besoin réel exprimé par des utilisateurs.
