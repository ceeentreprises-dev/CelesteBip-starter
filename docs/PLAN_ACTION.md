# Plan d'action CelestBIP — 90 jours

Suivi des tâches : onglet **Issues** du dépôt (une issue = une tâche, étiquette = chantier).

## 1. Financement : toutes les sources, par ordre de mise en place

| Canal | Pour qui | État | Action restante |
|---|---|---|---|
| PayPal (liens de paiement) | Clients particuliers, petits montants | Formulaires prêts | Confirmer les 4 liens, coller les URL dans `OFFERS` / `DONATION_URL` |
| GitHub Sponsors | Développeurs, soutiens réguliers | Inscrit, bouton `FUNDING.yml` actif | Créer 3 paliers : 5 / 15 / 50 USD par mois |
| Virement IBAN suisse / QR-facture | Entreprises, communes, sponsors | Code prêt (`support-approved.json`) | Décider si l'IBAN est publié (il révèle le titulaire) ou envoyé seulement sur facture |
| Stripe | Carte, TWINT, abonnements automatiques | Compte à compléter | Nom commercial + vérification d'identité dans le tableau de bord |
| Sponsoring d'actions | Entreprises locales, coworkings, banques régionales | Dossier PDF en ligne | 10 contacts / mois, proposition d'une page |
| Fondations et soutiens publics | Projets d'inclusion numérique | À étudier | Nécessite souvent une association : décider au jour 60 selon les recettes |

## 2. Publications

- **1 article par semaine** sur le site (`articles/*.md`, publié automatiquement au push).
- Thèmes prévus : IA et données personnelles au quotidien · Écrire un courriel pro avec l'IA · L'IA pour les aînés · Préparer un rendez-vous administratif · Résumer un document sans fuite de données · 10 demandes utiles pour indépendants.
- **Réutilisation** : chaque article → 1 publication LinkedIn + 1 message dans les groupes locaux pertinents (sans envoi de masse).
- **Code** : une version publiée (tag `vX.Y.Z`) à chaque évolution notable, notes dans `CHANGELOG.md`.

## 3. Calendrier

| Période | Objectif | Indicateur |
|---|---|---|
| J1–J7 | Paiements actifs, 20 prospects listés | 4 liens PayPal en ligne |
| J8–J30 | 10 entretiens, premières ventes | 3 paiements encaissés |
| J31–J60 | Atelier pilote livré, témoignages | 10 participants, 3 témoignages |
| J61–J90 | Récurrence et sponsoring | 10 adhésions, 1 partenaire pilote |

Décision au jour 30 : si moins de 3 paiements, changer le public ou l'offre, pas le budget.

## 4. Règles de fonctionnement

- Aucune dépense avant recette correspondante.
- Recettes : 30 % mis de côté (impôts, AVS, imprévus) dès le premier franc.
- Identité publique : le profil GitHub uniquement. Les données légales restent chez les prestataires de paiement.
- Suivi hebdomadaire : contacts, réponses, ventes, recettes encaissées, temps passé, frais, satisfaction.
