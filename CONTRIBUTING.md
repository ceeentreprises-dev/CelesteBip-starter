# Contribuer à CelestBIP Starter

Merci de votre intérêt ! Le projet reste volontairement petit et lisible.

## Règles simples

1. **Un seul fichier de code** : `CELESTBIP_MASTER.py`. Pas de dépendance obligatoire.
2. **Aucun appel réseau, aucune collecte de données, aucun paiement actif par défaut.** Toute proposition qui change cela sera refusée.
3. **Tout changement passe les tests** : `python CELESTBIP_MASTER.py test` et `python -m unittest discover -s tests -v`.
4. **Textes en français clair**, sans jargon inutile, sans promesse exagérée.
5. **Accessibilité** : contrastes, navigation au clavier, lisibilité sur téléphone.

## Proposer une modification

- Ouvrez d'abord une *issue* qui décrit le besoin.
- Faites ensuite une *pull request* courte, avec un seul objectif.
- N'ajoutez jamais de données personnelles, de clés API ou de coordonnées bancaires dans le dépôt.

## Signaler un problème de sécurité

Ouvrez une issue sans détail sensible, en demandant un contact privé. Ne publiez pas de faille exploitable.
