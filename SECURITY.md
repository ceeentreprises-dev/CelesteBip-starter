# Sécurité

Ce dépôt ne contient aucun secret, aucune clé et aucune donnée personnelle. Le site est statique et ne collecte rien.

Pour signaler un problème (lien trompeur, faille dans le générateur), ouvrez une issue sans y mettre d'information sensible, ou utilisez l'avis de sécurité privé de GitHub (onglet Security du dépôt).
