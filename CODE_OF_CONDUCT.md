# Règles de conduite

CelestBIP est un projet ouvert à toute personne, débutante ou non. Pour que chacun s'y sente à l'aise :

- Soyez respectueux : pas d'insultes, de harcèlement ni de discrimination.
- Critiquez les idées et le code, jamais les personnes.
- Ne publiez aucune donnée personnelle (la vôtre ou celle d'autrui) dans les issues et commentaires.
- Pas de publicité, de spam ni de liens commerciaux sans rapport avec le projet.
- Aucune promesse de gain ou de résultat : nous nous en tenons aux faits vérifiables.

Un message qui enfreint ces règles peut être masqué ou supprimé. Pour signaler un problème, ouvrez une issue sans y mettre de données sensibles.
